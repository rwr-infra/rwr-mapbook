{#- 「当前这一页属于哪种语言」——语言前缀的唯一判据。 为什么要有这个文件 ------------------ 站点的网址只按语言分层，**默认语言没有前缀**： / 默认语言（zh-hans） /en/prepare/ 英文 /zh-hant/prepare/ 繁体 /prepare/ 默认语言的那个分区 模版原先在十来个模板里各写一遍 `here[:3] == "en/"`，那种写法在语言目录不止 两三个字符时就会**静默判错**：页面被当成默认语言，站名、标注文案、面包屑 全落到错误的一支，而构建不报错。判据只留在这里一份。 语言目录**不是硬编码**的，从 config.extra.alternate 的 link 推导 （`./`、`zh-hant/`、`en/`）。加一种语言只需要动 zensical.toml 一条。 用法 ---- {% import "partials/route.html" as route with context %} {% set here = page.url | default("", true) %} {% set ldir = route.lang(here) | trim %} → "" 或 "en" / "zh-hant" {% set tail = route.tail(here) | trim %} → 去掉语言前缀后的页内路径 {% set L = route.suffix(ldir) | trim %} → "" 或 "_en" / "_zh_hant" ⚠️ 这个文件的说明里不能出现 Jinja 的行内注释标记：`{#` 与它配对的第一个 `#}` 之间不嵌套，写进去会把说明**提前截断**，后面那几行就变成真的模板代码了。 这处踩过一次——报错是「undefined has no method named lang」，看着像宏没导入， 其实是说明断在了半路。 宏的返回值是**字符串**，空的宏渲染出来是空串，所以要 `| trim` 再用； 判等一律拿字符串比（`ldir == "en"`），不要依赖布尔怎么序列化—— 模版里为这件事踩过一次坑，见 partials/lang-same.html 的说明。 -#} {#- ── 语言目录清单，从配置推导 ──────────────────────────────────────────── alternate 的 link 去掉 "./" 与斜杠就是目录名（`./`、`zh-hant/`、`en/`）。 不硬编码语言名：加一种语言只需要在 zensical.toml 里加一条 alternate。 MiniJinja 的字符串没有 split / find，所以一律直接遍历配置里的列表， 不在模板里把清单拼成字符串再切开。 -#} {#- 页面网址落在哪种语言里；默认语言返回空串。 -#} {% macro lang(url) %} {%- set u = url | default("", true) -%} {%- set ns = namespace(found="") -%} {%- for alt in config.extra.alternate | d([], true) -%} {%- set d = alt.link | d("./", true) | replace("./", "") | replace("/", "") -%} {%- if d and u[:d | length + 1] == d ~ "/" -%}{%- set ns.found = d -%}{%- endif -%} {%- endfor -%} {{- ns.found -}} {% endmacro %} {#- 去掉语言前缀之后的页内路径。 -#} {% macro tail(url) %} {%- set u = url | default("", true) -%} {%- set d = lang(u) | trim -%} {{- u[d | length + 1:] if d else u -}} {% endmacro %} {#- 语言目录 → 配置键名后缀。`-` 与 `.` 都换成下划线：zh-hant → _zh_hant。 -#} {% macro suffix(lang_dir) %} {{- ("_" ~ lang_dir | replace("-", "_") | replace(".", "_")) if lang_dir else "" -}} {% endmacro %} {#- 该页面地址的语言前缀，带尾斜杠；没有前缀（默认语言）返回空串。 语言切换器用它替换语言那一层——不用 tail()，否则会把页内路径也带上。 -#} {% macro base(url) %} {%- set d = lang(url) | trim -%} {{- d ~ "/" if d else "" -}} {% endmacro %} {#- 两个网址是否同语言。 -#} {% macro same(a, b) %} {%- set ua = a | default("", true) -%} {%- set ub = b | default("", true) -%} {{- "yes" if (lang(ua) | trim) == (lang(ub) | trim) else "" -}} {% endmacro %} {#- 一个网址里的锚点段（含 `#`），没有则返回空串。 标签胶囊用它把 `en/tags/#tag:x` 剥成 `#tag:x`。 MiniJinja 没有 str.find / str.split，所以这里逐字符扫一遍—— 网址都很短，且这样不会因为某个标签名里出现 "tags/" 而切错位置。 -#} {% macro anchor(url) %} {%- set ns = namespace(found="", on=false) -%} {%- for ch in url | default("", true) -%} {%- if ch == "#" -%}{%- set ns.on = true -%}{%- endif -%} {%- if ns.on -%}{%- set ns.found = ns.found ~ ch -%}{%- endif -%} {%- endfor -%} {{- ns.found -}} {% endmacro %}
