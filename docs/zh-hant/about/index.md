## 哪些地方還沒查證

不是每一行都試過。這些地方在頁面上明確標着，讀的時候請當心：

| 標記 | 意思 |
| --- | --- |
| **待試** | 整頁都還沒逐項驗證過，比如 mapSettings 那一頁 |
| **未完成** | 只寫到一半，或只有一句話提及 |
| 沒試 / 不知道這是啥 | 那一行作者也沒驗證過，**照着填可以，別當成結論** |

「據說是這樣」的說法也原樣留着。**這份手冊不替讀者作判斷。**
