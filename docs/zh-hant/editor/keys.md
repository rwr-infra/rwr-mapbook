# 交互按鍵表 { #keys }

<p class="kicker">EDITOR · 手放在哪裡</p>

!!! question "這張表收錄全了嗎"
    這一頁頂上空了一行「（真收錄全了嗎）」——那就是**沒驗過**。
    後面用着發現少了的，直接補進下面的表裡。

| 按鍵 | 作用 |
| --- | --- |
| ++f5++ | 刷新地編界面，以及清理非法元素 |
| ++tab++ | 切換俯視角與自由視角 |
| ++w++ ++a++ ++s++ ++d++ | 控制方向 |
| 鼠標滾輪 | 俯視角下調整縮放；自由視角下調整攝影機移動速度 |
| ++q++ ++e++ | 自由視角下調整攝像頭高度 |
| ++esc++ | 取消選擇；攝像頭鎖定鼠標 / 鼠標脫鎖 |
| ++shift+1++ | 切換到 Select 工具 |
| ++x++ | 筆刷橫向鎖定 |
| ++y++ | 筆刷縱向鎖定 |
| ++r++ | 旋轉選擇的對象 |
| ++g++ | 移動選擇的對象 |
| ++ctrl+c++ | 複製對象 |
| ++ctrl+v++ | 粘貼對象 |
| ++ctrl+z++ | 撤回 |

!!! tip "兩個不在這張表裡的"
    相機 mod 的 ++f3++–++f7++ 是另一套，見[準備工作 → 三](../prepare/index.md#camera-mod)。

    還有 ++f5++ 在這一頁是**刷新地編**，在相機 mod 裡是**開法線模式**——
    同一個鍵，取決於你開了哪個。
