# 交互按鍵表

（真收錄全了嗎）

| 按鍵 | 作用 |
| --- | --- |
| F5 | 刷新地編界面以及清理非法元素 |
| Tab | 切換俯視角與自由視角 |
| W、A、S、D | 控制方向 |
| 鼠標滾輪 | 俯視角為調整縮放，自由視角為調整攝影機移動速度 |
| Q、E | 自由視角下調整攝像頭高度 |
| Esc | 取消選擇、攝像頭鎖定鼠標/鼠標脫鎖 |
| Shift+1 | 切換到Select工具 |
| X | 筆刷橫向鎖定 |
| Y | 筆刷縱向鎖定 |
| R | 旋轉選擇的對象 |
| G | 移動選擇的對象 |
| Ctrl+C | 複製對象 |
| Ctrl+V | 粘貼對象 |
| Ctrl+Z | 撤回 |
