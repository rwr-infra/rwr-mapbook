# 谢谢

<p class="kicker">THANKS · 写给把这件事做出来的人</p>

这份手册不是一个人写完的。界面上的每一格、清单里的每一行、那些「加载时崩溃」
和「无碰撞箱」的结论，都是有人真的去试了、撞了、记下来，才有得写。

谢谢**做地图的人**——是你们一趟趟进游戏、退出来改配置，把地编摸成了现在这样。

谢谢**记笔记的人**——手边有答案时随手写下来这件事，看起来毫不费力，
但它让后来的人少绕了很多弯路。

谢谢**回来补的人**——那些「待试」和「没试，不知道这是啥」被一条条填上的时候，
这一页就比昨天更有用一点。

    修图的人比修图本身重要。
