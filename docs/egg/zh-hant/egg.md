# 謝謝

<p class="kicker">THANKS · 寫給把這件事做出來的人</p>

這份手冊不是一個人寫完的。界面上的每一格、清單裡的每一行、那些「加載時崩潰」
和「無碰撞箱」的結論，都是有人真的去試了、撞了、記下來，才有得寫。

謝謝**做地圖的人**——是你們一趟趟進遊戲、退出來改配置，把地編摸成了現在這樣。

謝謝**記筆記的人**——手邊有答案時隨手寫下來這件事，看起來毫不費力，
但它讓後來的人少繞了很多彎路。

謝謝**回來補的人**——那些「待試」和「沒試，不知道這是啥」被一條條填上的時候，
這一頁就比昨天更有用一點。
