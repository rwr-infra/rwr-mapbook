# ID 搜索功能说明 { #id-search }

<p class="kicker">EDITOR · 报错里那个数字是什么</p>

地编报错时通常会给出一个 ID。按这个 ID 就能把对应物件在地图上找出来——
这是修图时最常用的方法。

1. 先在报错信息里看 ID（或者看下面「找问题」那几张图里 ID 出现的位置）。

    ![报错里的 ID](../assets/editor/050.png)

2. 把 ID 填进搜索框搜索。

    ![在搜索框里按 ID 搜](../assets/editor/051.png)

!!! tip "ID 会变"
    地编每次保存后都会重新排一遍 ID，编号可能和上一次不一样。
    所以**记下来的是当时的 ID**；隔一次保存再搜，未必还是它。
