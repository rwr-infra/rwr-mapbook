# 交互按键表 { #keys }

<p class="kicker">EDITOR · 手放在哪里</p>

!!! question "这张表收录全了吗"
    这一页顶上空了一行「（真收录全了吗）」——那就是**没验过**。
    后面用着发现少了的，直接补进下面的表里。

| 按键 | 作用 |
| --- | --- |
| ++f5++ | 刷新地编界面，以及清理非法元素 |
| ++tab++ | 切换俯视角与自由视角 |
| ++w++ ++a++ ++s++ ++d++ | 控制方向 |
| 鼠标滚轮 | 俯视角下调整缩放；自由视角下调整摄影机移动速度 |
| ++q++ ++e++ | 自由视角下调整摄像头高度 |
| ++esc++ | 取消选择；摄像头锁定鼠标 / 鼠标脱锁 |
| ++shift+1++ | 切换到 Select 工具 |
| ++x++ | 笔刷横向锁定 |
| ++y++ | 笔刷纵向锁定 |
| ++r++ | 旋转选择的对象 |
| ++g++ | 移动选择的对象 |
| ++ctrl+c++ | 复制对象 |
| ++ctrl+v++ | 粘贴对象 |
| ++ctrl+z++ | 撤回 |

!!! tip "两个不在这张表里的"
    相机 mod 的 ++f3++–++f7++ 是另一套，见[准备工作 → 三](../prepare/index.md#camera-mod)。

    还有 ++f5++ 在这一页是**刷新地编**，在相机 mod 里是**开法线模式**——
    同一个键，取决于你开了哪个。
